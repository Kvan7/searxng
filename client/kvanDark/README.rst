=====================
MEMO vite development
=====================

Local install::

  # in folder ./client/kvanDark/
  $ npm install

Start development server::

  $ ./manage vite.kvanDark.dev

  # in folder ./client/kvanDark/
  $ npm exec -- vite

Fix source code::

  # in folder ./client/kvanDark/
  $ npm run fix

Fix & Build::

  $ ./manage vite.kvanDark.build
